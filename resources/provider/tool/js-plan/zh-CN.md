# 工具 · js-plan

读写规划底稿 `P` 的编程面。`P` 是本任务唯一可持久读写的文件，路径由系统派生，你不在参数中指定路径。

## 契约与使用

1. **单一目标**：只作用于当前任务的底稿 `P`。不提供目录列表，不读写任何其它文件。
2. **能力原语**：`read()` 读全文；`edit(patches)` 做精确局部补丁；`rewrite(content)` 全量覆盖。修改先暂存、后原子提交。
3. **无仓库能力**：本编程面没有 glob、grep，也不访问仓库文件。需要仓库事实时用 `ask`。
4. **底稿即状态**：`P` 的当前内容是唯一事实。每任开始先读再写，不依赖对上一任内容的记忆。
