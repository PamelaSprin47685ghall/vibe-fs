How many recent todowrite checkpoints, including this call, should remain as raw context. Use 1 to allow compression directly before this todowrite. Use 2 to keep this and the previous todowrite, allowing compression before the previous one. Larger values keep more recent raw history. Choose it independently on every call. It can only limit future compression and cannot restore history already replaced by LWR; a value beyond the currently recoverable raw range is equivalent to requesting no additional compression.
