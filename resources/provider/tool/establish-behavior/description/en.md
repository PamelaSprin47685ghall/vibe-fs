Entrust a Coder to change source so that the intended behavior is represented
by executable evidence in the written repository.

Use this when the operational objective already determines what behavior must
be established, but stable source-level evidence for that behavior does not yet
exist.

The Coder writes source, including tests when appropriate.

This tool does not run those tests.
A Coder completion is not execution evidence.

After the source change returns, you remain responsible for observing the
behavior in the running world.
