To compress context, supply both top-level parameters: `prefixCount` and `carry`. The prefix stays unchanged; the array follows in order. Integers copy visible anchors' full intervals, and strings are literal text. At `[ANCHOR: 7; prefixCount: 3]`, use `7` to reference this interval or copy `prefixCount: 3` to keep everything through it. Use `0` for no history prefix. Unselected history is dropped. Omit both parameters to keep the current context.

**The current turn is kept automatically.** Write new conclusions in ordinary text before compressing; they need no anchor or duplicate in `carry`. Keep the constraints, evidence, and open questions needed next, without carrying old material that repeats your new text. The host removes `carry` from the retained call record so literals appear only once.
