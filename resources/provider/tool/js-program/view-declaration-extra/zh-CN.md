声明视图时同时提供 `prefixUntil` 和 `thenMap`。边界以下的锚点受到保护，不接受新替换；升降边界不会恢复此前的材料。`thenMap` 把非负锚点编号映射为 null（保留）或非空白摘要。未列出的锚点保持不变。

摘要取代该存活锚点至下一个存活锚点之间的区间。每项操作在本轮声明执行前固定边界，因此相邻摘要互不吞并，晚到消息也不进入旧末尾替换。替换历史按顺序累积。被替换的真实锚点不再存在；隐含锚点 0 始终代表开头区间，包括以前的摘要。

只有用户消息和终态工具结果带有原位 `[ANCHOR: N]` 标记。Plan 的真实用户原文不能被取代，忽略的尝试会列在回执中。provider 投影不改写原始消息或 Trace。

编号与摘要只在本进程有效。持久 checkpoint 记录调用身份，不保存视图材料。视图不能恢复任期隔离已移除的内容。须长期保留的知识写入 P。
