**顶层布局（每次调用必填）：** `prefixUntil` 与 `carry`。

这两个字段只决定**下一请求**的可见历史。它们不是 `fork` / `resume` / `deliver` / `advisor` / `devops` 的成员参数。

- `prefixUntil`（数字，必填）：保留锚点编号**严格小于**该值的全部可见区间。截止值不包含其本身。看到 `[ANCHOR: 7]`，填 `prefixUntil: 7` 表示截到 7 之前；若还要保留 7 及之后仍可见的区间，填更大的数。
- `carry`（数组，必填）：接在上述前缀之后，按顺序追加材料。整数复制可见锚点的完整区间，字符串是字面文本。不需要额外材料时填 `[]`。
- 省略任一项都会报错。不存在靠沉默「保留全部历史」的默认。
