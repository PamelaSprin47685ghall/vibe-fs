The `todowrite-for-manager` program entry stays available across review stages. Repository access exists only under `this.reviewOnly`: `cat`, `stat`, `ls`, and `rg` have no top-level aliases. Before each access the Host checks that the current incumbency still has an unaccepted review. Accepted review, final incumbency, cleanup blockers, and retirement freeze refuse access with `REVIEW_ONLY`. Saved objects or methods and resumed programs do not retain old permission. `where` and `whereAll` operate on supplied text and stay at the top level. Delegation and lifecycle members keep their own permission checks.
