把一条独立道路托付给本 campaign 中的 Manager。

当工作可以独立推进、并且有自己连贯的目的地时，才 commission 另一条道路。
检验标准是目的是否独立，不是劳动量大小，也不是它在生命周期中的位置。

不要仅仅因为工作很大、或已经进入下一阶段，就另开一条道路。
同一目的地的后续阶段仍然是同一条道路。

这不是 fork：它不会在一条 mission 里再开一个 Office。
这不是技术阶段，也不是 Host admission machinery。

成功返回只证明被命名的道路已经接下 charge。
它不证明目的地已经到达。

新道路须同时给出 calling + name + charge。
继续已知道路时，省略 calling，并使用同一个 name。

calling 选择 Coordinator / Lead（区别在 persona 与 reasoning depth，不是不同的 Office）。
name 是这条道路的 byname。
charge 是目的地与 constraints，不是对隐藏 tools 的指定。
