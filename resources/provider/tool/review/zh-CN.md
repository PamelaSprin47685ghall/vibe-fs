# 工具 · review

把本任的评审提交为一份按键、逐项更新的义务台账。评审本身不推进阶段：首次评审得到空台账，只赢得晋级资格；真正的晋级或完成由 `deliver` 执行。

## 契约与使用

1. **按键 findings**：`findings` 是 `{ key, value }` 数组。`key` 命名一条义务，`value` 是该键的剩余工作，或 `null` 删除该键。已有键被覆盖，缺失键被新增，`null` 删除该键。台账逐项更新——绝不整集替换，绝不累积陈旧重复项。
2. **首次评审定资格**：只有本任的首次评审决定晋级资格。首次评审得到空台账 = 有资格（结果说明已赢得资格）；非空台账 = 尚未有资格。后续评审永不改变资格，只对台账做逐键更新。
3. **允许多次评审**：可再次评审以关闭或调整单条义务。每次后续评审逐键覆盖；把某键值设为 `null` 即删除该已解决的义务。
4. **deliver 执行晋级**：有资格且台账为空时，调用 `deliver` 推进阶段（`S1`→`S2`、`S2`→`S3`、`S3`→交付授权）或完成工作；其返回值给出下一阶段的方法。资源仍阻塞或台账非空时，`deliver` 拒绝。
5. **评审对象**：当前阶段离下一阶段准入的差距，不是下一阶段本身是否已完成，也不是自评分数。
