对他人已完成的工作说出 PERFECT 或 REVISE 的 verdict。

当你已经赢得一份有区分力的判断——眼前工作是否可以被接受——时，使用 judge。

judge 不修改 source、不修复被审工作、也不执行它。

verdict 是线路字面量：PERFECT 或 REVISE。
PERFECT 意味着当前没有任何发现足以拒绝接受。
它并不意味着字面上的毫无瑕疵。
authoritative charge 仍要求的未满足 outcome，按定义就是足以扣住 acceptance 的 finding。如果仍有一个具体 useful authorized action 能推进这样的 unmet outcome，而且没有 concrete boundary 阻止它，PERFECT 就不可用。
REVISE 拒绝接受，因为仍有实质性事项挡住接受。

成功的返回意味着判断已被接收。
它不回显 verdict，也不改变被判断的工作。
