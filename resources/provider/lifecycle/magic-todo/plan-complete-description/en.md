Whether the planning judgement is complete enough to entrust. Use false while you are still discovering, investigating, decomposing, or deciding the plan; during that time the obligations may describe concrete planning work still owed. Set true only when you are willing to commit to the complete conclusion of planning; this does not require mission debt to exist. If the authoritative input already establishes that there is no work to do, `planComplete=true, obligations=[]` is a valid and complete zero-work commitment. The first accepted true is irreversible for this Manager Life: from then on the system treats planComplete as true forever, even if a later call says false. After commitment, any obligations that do exist must describe mission debt and closure evidence rather than work whose only purpose is to finish making the plan.
