## Scope & Context Management (`resetScope`)

- **Turn & Budget**: 1 LLM request = 1 turn. Only in the outgoing model request, completed tool results show the remaining `turnBudget`; until a `resetScope` call follows the latest operator-authored user message, non-`resetScope` results instead show the initialization reminder. Raw tool results and stored history remain unchanged. Call `resetScope` before `turnBudget` reaches 0.
- **Exhausted Budget**: At 0 remaining, a weak, optional steer may suggest `resetScope` if you are not busy and at a natural boundary. Never interrupt, pause, or abandon work in progress for this reminder; reset when convenient.
- **Context Deletion**: Calling `resetScope` removes the old scope's raw context from subsequent model requests. From the previous `resetScope` call (or session start) up to this call, only user messages and prior `resetScope` call/result pairs survive. Everything after this call belongs to the new scope.
- **User Messages Are Not Barriers**: User prompts and mid-run steers are never deleted. Every new operator-authored user message invalidates `turnBudget` and requires an immediate `resetScope` to archive the scope from the previous `resetScope` call (or session start) up to the new reset. All user messages in that window survive in order; they do not split the window.
- **Concurrency Barrier**: `resetScope` is an execution barrier. Within a single turn, earlier tool calls finish before `resetScope` runs; later calls wait for it to finish. Earlier non-`resetScope` calls and their results are removed from context; calls after the barrier remain in the new scope.
- **State Closed-Loop (状态闭环)**: Each scope must be a self-contained state closed-loop. For example, "pure exploration to locate files and understand their logic" is one closed-loop; "reading and modifying files" is another.
- **Verbatim Retention**: Raw context from the old scope will be deleted. Any text needed word-for-word in the next scope (such as function signatures, error stack traces, or exact line numbers) MUST be copied VERBATIM into `oldScopeVerboseVerbatimExperience`.
- **Initialization Reminder**: Every operator-authored user message in a provider request copy ends with: [System: Estimate the turnBudget for the first fine-grained task block (state closed-loop). Then call resetScope immediately, before doing anything else.] That reminder is an explicit order: estimate the budget for the first state closed-loop and call `resetScope` before any other work.
