# repeated-known-mistake — Enforcer

## Definition
Current work repeats a mistake, failed approach, or violated constraint already recorded in the work log or project guidance.

## Trigger When
Current work repeats a mistake, failed approach, or violated constraint already present in the work log or project guidance.

## Do Not Trigger When
Do not fire when the prior note is obsolete and the change intentionally supersedes it with a recorded new decision.

## Distinguish From
unrecorded-lesson failed to capture learning; this tip ignores learning that already exists.

## Decision Procedure
1. Name the concept
2. Name the boundary
3. Ask if a primitive crosses it
4. Prefer a distinct type

## Nudge
The work is repeating a previously recorded mistake. Re-read the existing lesson and change the approach.

## Examples
### Positive

### Near miss
A related situation that shares vocabulary but does not cross this tip's boundary — see Distinguish From.
