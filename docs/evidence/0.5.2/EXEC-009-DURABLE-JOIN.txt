Algorithm
---------
1. Completion path (HostForkRunLifecycle.complete):
   - Build AgentCompletionOutcome from TerminalOutcome.
   - Encode durable blob body via HandleCompletionBlob.encodeOutcome.
   - HandleController.recordCompletion: WriteBlob BEFORE HandleCompleted fact.
   - Terminal / SendFailure → Some(ref, digest); Cancelled → None (cancelChildren).
   - Then mailbox Source.SetResult (notification only).

2. Join path (HostForkRuntime.Join):
   - Projection-first: HandleProjection.joinable is the fact source.
   - For each joinable agent handle:
       tryRead blob → HandleController.consume (CAS HandleRetired).
   - Concurrent losers: AlreadyRetired → try next / re-loop.
   - CommitUnknown / AppendFailed → Error, MUST NOT deliver payload.
   - If none joinable: await mailbox.
       - PTY completion (EXEC-015): return mailbox payload as-is.
       - Agent completion: discard payload, re-loop (notification only).
   - Empty mailbox after restart: joinable from durable projection still works.

3. Restart (HostForkRestart.restoreLinkedChildren):
   - Retired: skip.
   - CompletedAwaitingJoin: Restore + BindChildSession; blob → PublishCompletion;
     no blob → transcript recoverChild fallback (0.5.1 lines).
   - Active: recoverChild (transcript / Interrupted).

4. Codec (FactCodec.migrateHandleCompleted):
   - 0.5.1 HandleCompleted lines missing CompletionRef/CompletionDigest
     → inject null → Decode as None (forward-compatible).

5. List / parent cancel:
   - ListTool reads HandleProjection.listable (same projection).
   - cancelChildren uses HandleProjection.activeHandles then Cancelled+Retire.
