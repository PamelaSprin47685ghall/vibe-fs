# 设计目录 — 54 方法论的 DSL 签名

## 位置公理（六模块划分已废弃）

- 方法的位置不由模块/文件/目录声明，由其类型签名在依赖图中的坐标决定。**签名即位置。**
- 定位维度互相正交：形态 · 输入门禁 · 产出权力 · 词法欠债。任何单维度归类（六模块或八层）都把正交维度压成抽屉——thought_experiment 与 bayesian_update 在六模块下的"跨界安置"尴尬，正是分类失败的证据（§2.3 同构：标签代替问题，结构丢失）。
- 形态只有三种：
  - 认识函数：`输入 -> Meditation<输出>`（绝大多数方法）
  - 组合子：高阶函数，词法化强制回路（表示变换全部 + memoize/anneal/swarm/sampleThenVerify）
  - 策略：纯函数值，控制层的参数（搜索层的空间声明与剪枝）
  - 谓词不是方法形态：它是控制层对 ledger 的纯查询（deriveObligations 的分支条件）。宪法层的"抢占"由义务排序表达，不进入方法签名。
- 文件组织是物理便利。依赖方向由类型引用自然形成：Proposal<'a> 只能流向 verifier，Accepted<'a> 只能流向 ledger 与报告。
- 以下按 §16 八层权力叙述的顺序浏览；顺序只是阅读顺序，不承载语义边界。

## 阅读约定

- 首参数为 oracle 端口（§37.1 任务专用注入），仅当方法本体需要 LLM 语义判断时出现；组合子无 oracle 参数，LLM 在被组合的函数内。
- 行尾注释只写签名看不到的：词法欠债、权力上限、触发条件。
- 权力三问（CanRaiseGrade/CanCloseUnknown/CanTerminateGlobally）默认 false/false/false，仅标注例外。

## 签名目录

### ① 宪法门禁 — 产出 frame/sense/spec/system；抢占在控制层义务排序

```fsharp
val clarifyIntent : IntentOracle -> UserUtterance -> Meditation<IntentFrame>
    // 义务 ClarifyIntent 最高优先 · 唯一可直达 Blocked 的方法

val disambiguateConcept : ConceptOracle -> ConfusedConcept -> Meditation<SenseTable>
    // 命中多义 → 义务 ClarifyScope 抢占概率与因果判断

val operationalize : OperationalismOracle -> VagueTerm -> Meditation<OperationSpec>
    // 不可操作化 → 抢占证据与数值编译

val axiomatize : PrimitiveTerms -> AllowedOps -> Invariant list -> Meditation<Result<FormalSystem, Inconsistency>>
    // 欠债 consistencyCheck · 原始术语不稳定时禁止进入

val stripToAtoms : FirstPrinciplesOracle -> ProblemStatement -> Meditation<AtomicBasis>
    // 剥离假设账本 → 原子事实 + 重建链
```

### ② 真值保持与反驳 — derivation warrant 的唯一来源

```fsharp
val deduce : AcceptedPremises -> ValidInferenceChain -> Meditation<DeductionResult>
    // grade ≤ 前提逐维 meet · 欠债 premiseAudit

val refuteByContradiction : AcceptedPremises -> AssumedNegation -> DerivationToContradiction -> Meditation<Refutation>
    // 只能排除假设，不能立论

val proveInvariant : OperationSet -> CandidateInvariant -> ObservationEvidence list -> Meditation<Accepted<Claim> option>
    // 效力限于声明的操作集

val pigeonhole : CountingArgument -> Meditation<Accepted<Claim>>
    // 前提：计数与容量事实已带 warrant

val necessaryPreconditions : UndeniableFact -> Meditation<NecessaryPremise list>
    // 只推必要前提，不推结论本身

val tryFalsify : CounterexampleOracle -> Accepted<Claim> -> FailureCondition list -> Meditation<FalsificationResult<Accepted<Claim>>>
    // Survives of scope | Refuted of counterexample · 无 ProvenTrue
```

### ③ 证据与现实检查 — observation warrant 的唯一来源（末两个例外见注释）

val traceFault : FailureSignature -> ReproductionSteps -> Meditation<FaultChain * ObservationWarrant>

val analyzeCause : WhyChain -> Meditation<CausalVerdict>

### ⑤ 表示变换 — 组合子：守恒义务词法化，缺一段即编译不过

```fsharp
val transformEquivalent :
    transform:('a -> Meditation<'b>) -> provePreserved:('a -> 'b -> Meditation<PreservationProof>)
    -> source:'a -> Meditation<Equivalent<'b>>

val withAuxiliary :
    construct:Meditation<'aux> -> use:('aux -> Meditation<'r>) -> discharge:('r -> Meditation<DischargeProof>)
    -> Meditation<'r>

val decompose :
    split:('a -> Meditation<'parts>) -> recombine:('parts -> Meditation<'b>) -> contract:InterfaceContract
    -> source:'a -> Meditation<'b>

val reduceDimension :
    project:('a -> 'b) -> reasonInSlice:('b -> Meditation<'r>) -> liftBack:('r -> Meditation<'a>)
    -> auditLift:('a -> Meditation<LiftRisk list>) -> source:'a -> Meditation<'a>

val viaDual :
    toDual:('a -> 'b) -> solveDual:('b -> Meditation<'r>) -> pullBack:('r -> Meditation<'a>)
    -> source:'a -> Meditation<'a * DualityGap option>

val viaQuotient :
    equiv:('a -> 'a -> bool) -> solveOnClass:('a -> Meditation<'r>) -> liftMap:('a -> 'r -> Meditation<'a list>)
    -> source:'a -> Meditation<'a list>

val mapStructure :
    objectMap:('a -> 'b) -> morphismMap:(('a -> 'a) -> ('b -> 'b)) -> proveCommutes:Meditation<CommutationProof>
    -> source:'a -> Meditation<'b>

val relax :
    relaxProblem:('h -> Meditation<'r>) -> solveRelaxed:('r -> Meditation<'a>) -> projectBack:('a -> Meditation<'h>)
    -> validateHard:('h -> Meditation<Validation>) -> source:'h -> Meditation<Validated<'h>>
    // §14.4 词法范例

val coarseGrain :
    microMap:('m -> 'M) -> relevant:Var list -> macroReason:('M -> Meditation<'r>)
    -> source:'m -> Meditation<'r * MicroCorrections option>

val simplify :
    source:'a -> reduce:('a -> Meditation<'b>) -> provePreserved:('a -> 'b -> Meditation<PreservationProof>)
    -> auditLoss:Meditation<LossAudit> -> Meditation<SafelySimplified<'b>>
    // SafelySimplified 构造私有 · 禁止 closeUnknown
```

### ⑥ 搜索控制 — 策略：纯函数值与高阶包裹，不产内容

```fsharp
val declareSpace : nodes:StateNode list -> moves:Move list -> SearchSpace
    // 纯值声明，交控制层执行

val pruneWith : bound:('b -> BoundWitness option) -> branches:'b list -> 'b list
    // 无 bound witness 不剪

val memoize : normalize:('p -> 'k) -> solve:('p -> Meditation<'r>) -> ('p -> Meditation<'r>)
    // 规范化相同子问题共享结果

val sampleThenVerify :
    seed:Seed -> count:int -> sample:(Seed -> Meditation<'s>) -> summarize:('s list -> Meditation<'r>)
    -> verifyDeterministically:('r -> Meditation<Validation>) -> Meditation<Validated<'r>>
    // 无确定性复核函数即编译不过

val anneal :
    objective:('s -> float) -> neighbors:('s -> 's list) -> schedule:CoolingSchedule
    -> verifyBest:('s -> Meditation<Validation>) -> initial:'s -> Meditation<Validated<'s>>

val swarm :
    candidates:'c list -> explore:('c -> Meditation<'c>) -> dedupeCanonically:('c list -> 'c list)
    -> independentCheck:('c -> Meditation<Validation>) -> Meditation<Validated<'c>>
```
