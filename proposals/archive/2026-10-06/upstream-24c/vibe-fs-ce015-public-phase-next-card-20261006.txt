2. What the clocks actually mean

The producer is requirements/verification-system/tests/support/worker-cost-observation.mjs.
It records process.cpuUsage() and performance.now() in the actual test worker,
before importing the entry and at process exit. The observer checks actual entry,
pid and parentPid agreement before publishing interval.

CPU below is (exit user + system - pre-import user - system), worker process only.
It is NOT CPU consumed by spawned Host, compiler, Git or other children. It can
include threads inside this process; a worker wall minus own CPU is not an I/O-only metric.
Parent span is runner:file-drained.elapsedMs minus runner:file-start.elapsedMs,
both in the parent runner clock. It is not parent CPU and includes the worker lifetime.
The last column is parent span minus the worker pre-import-to-exit interval.
It includes startup before pre-import, post-exit transport/drain and parent scheduling;
it must not be described as pure pipe latency.

Units: milliseconds. Every row below has a complete same-worker cost pair.
