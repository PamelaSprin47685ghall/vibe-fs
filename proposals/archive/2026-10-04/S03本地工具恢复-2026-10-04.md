# S03：选定 SDK 的本地工具恢复

接续[完整 SDK 准备](S03选定SDK准备-2026-10-04.md)，本批增加 `prepareVerificationDotnetTools`。它消费原 `global.json`、原 `.config/dotnet-tools.json`、已准备 SDK 和明确 ID、版本、SHA512 的 nupkg 归档；不使用当前用户的 NuGet cache 或 resolver 作为安装来源。

## 已实现边界

manifest 必须为 root v1、精确版本和唯一命令，不接受 floating version 或 rollForward 掩盖版本漂移。每个归档一次读取，先核完整 SHA512，再写入自有 feed；配置清空外部源与 fallback，选定 SDK 实际执行 tool restore，HOME、CLI、NuGet 与临时目录均私有。

实际 package ID/version 集合必须等于选定集合，恢复的 nupkg 字节必须与原归档相同。resolver 每条命令须匹配 manifest 的名字和版本，入口 DLL 只能来自对应私有包。依赖清单的 runtime target、普通相对 asset 路径及平铺 runtime DLL 必须真实存在；不按 deps 中的 library 标签另造一份 NuGet 包图。

完整输出库存包含目录模式、文件字节、大小与摘要，连同原 manifest/global、选定包集合和 SDK 身份形成工具 receipt。原 restoreRoot 保留，保证 resolver 的绝对路径仍有效；它是该次恢复的自有实例，不冒称可重定位归档。失败或取消等待执行结束后回收自有根，保留原 Error/null；dispose 不删除调用方拥有的 SDK。

正式反例保留在 `016.test.mjs` 注册的支持用例中。已有 runtime DLL 缺失、坏 deps JSON、外逃 asset 的三条真实红证，再补实现；取消与父子进程排空、版本和摘要错误、未选包/命令、完整库存改字节/权限/增删均有公开行为断言。运行数量、红绿原始日志与最终统一门禁见[验收记录](baselines/2026-10-04-dotnet-tools-acceptance.txt)。

复核补齐另外三条正式红：feed 新增未选成员、SDK 入口字段变更、父目录链接换向。feed 必须保持完整选定集合；SDK receipt 的入口与原摘要核对，真实 SDK owner 的公开 root/receipt 也绑定到原私有闭包；临时目录从 canonical parent 分配，清理不再沿后来换向的别名走。真实 SDK root 字段替换亦先取得正式红后修复。以上都是准备与清理边界，不能据此宣称过程内 ABA 已解决。

## 真实输入与消费

真实 integration 明确选择完整 SDK10.0.302，按原 global10.0.100/latestFeature 准入。Fable5.13.0 与 Fantomas6.3.0 包从 NuGet 官方 flat-container 下载，以明确 SHA512 选定；输入来源、官方元数据及摘要核对单独保留，不把缓存诊断认成来源证明。独立工具根真实恢复后，即使删除夹具拥有的外部包/SDK归档，原选定 SDK 仍可执行两个实际 DLL，并返回其真实版本；最后按所有权分别回收工具与 SDK。

微软文档说明 [tool restore](https://learn.microsoft.com/en-us/dotnet/core/tools/dotnet-tool-restore) 使用 manifest 安装本地工具，[NuGet 依赖解析](https://learn.microsoft.com/en-us/nuget/concepts/dependency-resolution) 区分版本约束与解析结果。本仓原工程 props 使用下界版本且无 tracked packages.lock，现 assets 引用用户 cache；不能直接归档旧 assets 就声称工程依赖图固定。

## 剩余施工

本批只完成本地工具准备，不是工程 NuGet restore、实际 Fable 编译、Git/OS 加载闭包、native Host、不可变执行或 verify 接线。工具版本探测不能替代编译；clear local feed 和私有目录不单独证明所有 OS 网络或共享库加载受控。runtime DLL 断言不覆盖任意 native/resources/runtimeTargets 策略。

下一项从选定源码、原 project/props 出发，用明确包字节捕获并复验工程解析图、包哈希及 SDK 内部 feed 身份，避免浮动范围、用户 fallback 和旧缓存补库。之后再接实际只读 Fable 和同候选 verify。GAP-055 保持 PARTIAL，T418/T419 不删除，旧父目录替换反例仍保留。
