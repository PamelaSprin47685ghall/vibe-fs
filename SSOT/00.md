## 架构 DNA（三条不可违反原则）

以下三条原则是整个万象术架构的决定性约束。完整规范见 SSOT/01.md。

1. 结构化程序替代状态机。 控制流只用 `let!/do!/use!/match/while/尾递归` 表达。禁止 `CurrentStage`、`FallbackPhase`、`Lease`、`Generation` 等程序计数器。
2. 事件是信号，不是数据。 碎片事件（`message.updated`、`part.delta`）直接丢弃。业务事实只从 SDK API 读取完整 snapshot。
3. 不修改 OpenCode 本体。 所有功能只通过现有插件 Hook 和 SDK API 实现。
