# behavior-diagnosis 测试与证明范围

规则只由 WHAT 定义。本目录说明用例实际经过的边界，不增加验收条件。

- 001/003/004/005：目录身份、结构、顺序、完整双语正文与确定性合成。002/005 将真实编译产物复制到隔离包，修改其中的资源，通过实际 loader 证明缺失、空白、非法目录及无 fallback；loader 抛错不等于已经证明插件进程 fail-fast。
- 006/007/008：实际文本/codec/目录判定；006 另经真实插件证明 NoLiveCycle 的终止与 Host 错误。007 用小目录区分精确命中、编辑距离和并列顺序，不把某一版的 120 条规则固定为永久数量。
- 009/010/017：decodeCycle 仅转换生产解码器结果，fixture 安装正式资源并提供 Host 消息。解码后的调用数量不代表原始调用基数；009 的真实混合有效/无效多调用仍待贯通。017 保留实际协调者、journal、发送、关闸、drain 及共享失败证据，未以源码参数名或自建状态分类代替。
- 011：512/128 KiB 直接取自 WHAT，以独立 UTF-8 字节数核对含中文的恰好边界和超一字节；静态 owner 检查的正反例仅证明该检查器自身。
- 012/013/014/015/016：分别覆盖实际 codec、coverage 出生与 fold、RecentTips、配对及 squash。codec 往返或分别调用两次 fold 均不能证明持久化原子事务；012/013 保留真正提交前校验与故障重开的缺证。
- 018 只证明当前内置资源视图一致；真实 BIRTH 在 in-flight life 中的冻结尚待证。019 不再使用测试自建 fatal 模型，必需注入及 durable settlement 的完整证明仍 TODO。020 以同文不同身份的合规输入证明结构校验不代行语义审阅，不声称所有规则已人工 Review。
