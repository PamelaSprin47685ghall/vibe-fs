# distribution 测试说明

行为规范见 [WHAT.md](../WHAT.md)。本目录包含打包产物、发布 Manifest 及安装完整性的测试。

## 测试覆盖重点

- **001/003/004/008/010**：检查打包产物目录、Manifest 清单及活跃角色注册。
- **002**：在独立工作目录下验证真实资源加载与模块导入，确保不依赖当前开发工作区环境。
- **005**：验证 Manifest 损坏或产物过旧时的构建阻断，以及失败时的安全清理机制。
- **006**：验证必要资源缺失时的显式报错与正常加载。
- **007/009**：验证归档文件结构的正确性（仅包含约定的根文件与分发文件），拦截越界打包。
- **011**：验证 wanxiangli 子模块依赖与独立加载行为。
- **012**：验证多语言资源的完整性与占位符对齐。

## 运行方式

```bash
# 运行本包单元测试
node scripts/verify.mjs --suites=distribution

# 验证发布打包（真实 pack、解包与隔离消费）
node scripts/verify-package.mjs
```
