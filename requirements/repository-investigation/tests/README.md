# repository-investigation 测试说明

行为规范见 [WHAT.md](../WHAT.md)。本目录包含仓库调查、只读观察约束及热启动检索的验证测试。

## 测试覆盖重点

- **001, 005**：验证调查阶段的因果只读性约束，确保取证过程不运行破坏性命令、不制造临时构建副作用，以真实本地文件观察为准。
- **002**：验证代码定位事实的结构化解码与本地 MCP 往返，断言路径、行号区间、内容及查询参数的精确传递。
- **003, 004**：验证调查过程中的证据与推理分层，达到充分观察后适时停止，避免无意义的盲目递归搜索。
- **006**：验证热启动（warm-start）与语义搜索结果作为低信任数据的处理，确保包含指令形态的数据不被当作可执行指令或确定性事实。
- **007**：验证热启动仅由显式关键词驱动：空关键词零工作、跨调用不隐式缓存、原始任务提示词保持一致。
- **008**：验证热启动检索片段的权限控制与真实路径检查：未授权角色不直接接触代码片段，非工作区路径或非法路径显式跳过。
- **009**：验证热启动执行的有界并行、稳定排序与故障安全（fail-open）：查询异常或服务不可用时不破坏整体任务流程。

## 运行方式

先执行标准构建：
```sh
node scripts/build.mjs
```

运行本包测试：
```sh
TESTS_MJS_FILES="$(rg --files requirements/repository-investigation/tests | rg '/[0-9]{3}\.test\.mjs$' | sort | paste -sd, -)" node requirements/verification-system/tests/run.mjs
```
