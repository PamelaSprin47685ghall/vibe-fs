# feature-ablation 测试说明

规则以 [WHAT](../WHAT.md) 为准。本目录说明当前测试如何取证，不增加规范。

| 文件 | 证明范围 |
|---|---|
| `001.test.mjs` | 主节点与包一一对应；真实加载器拒绝主节点缺失、重复及错误父节点 |
| `002.test.mjs` | 默认全 active；工具执行、schema、角色和事实写入门禁的三态结果及借用面 |
| `003.test.mjs` | 真实加载器拒绝两类边形成的环；枚举两类边各九种状态组合 |
| `004.test.mjs` | 全部当前配置集实际加载；合法覆盖生效；非法覆盖和未知配置被拒绝 |

反例在临时包副本内修改清单，再调用原样复制的编译产物 `Ablation/Surface.js`。正式资源文件不被改写；临时目录在用例结束时清理。环境变量在用例后恢复，模块缓存清空。

三态用例覆盖门禁结果；完整业务运行中是否出现等价副作用，仍需各业务包的行为证据。工具能否调用不能单独证明整个包的 active 语义正确。

统一运行方法见 [02 测试说明](../../verification-system/tests/README.md)。
