规范见 [WHAT.md](../WHAT.md)。测试验证调用界面的契约说明、参数定义及工具边界。

## 测试覆盖重点

- **001**：检查工具注册描述非空，确保重要参数（如 `assume` 的 `assumption`）具备明确的语义说明。
- **007/008**：验证静态工具名称与活跃角色名称的清晰分离，避免同名冲突。
- **009**：验证工具 Schema 与中英文资源不宣传已废止的协调角色选项。
- **014**：验证 `assume` 仅接受 `assumption` 参数，成功时不回显冗余信息，且不维护内存画板。
- **015**：验证原生 `todowrite` 的透传与定义不被改写。
