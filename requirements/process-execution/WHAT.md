# process-execution — WHAT

## [001] 终端四动词

终端分别提供 `open-terminal`、`send-terminal`、`read-terminal`、`signal-terminal`，对应打开、写入、读取增量与发送信号；不同物理动作不合并为模糊口令。

PTY 监管须能从编译型 Bun 宿主启动，不要求宿主可执行文件默认充当 Bun CLI。内部 worker 的启动标记不得泄漏给目标命令；目标保留调用方环境，启动 worker 不改写宿主环境。

## [002] 动作与观察分离

命令与信号是物理动作，stdout/stderr 是观察；输出不能充当任务完成或下一动作的授权。

## [003] 真实退出决定物理完成

只有底层实际退出事件能确认进程完成。输出停止或发送终止信号均不等于退出。

未确认退出的 PTY ID 不得被另一次启动覆盖；只有观察到旧实例退出后才可复用该 ID。批量清理须尝试每个所属实例，再报告未能确认退出的错误，不能因前一项失败而遗漏后续实例。

PTY 的目标退出和监管范围结束分别观察。目标先退但本次控制终端会话仍有活进程时，不得发布完成或释放归属。成员表必须包含本次活 owner，且各行完整；空输出、缺 owner、残行或冲突行均是未确认，不能解释为会话为空。有效成员还须核对本次 SID；监管者失联或缺少确切结束回执时保留 Unknown，并使等待中的排空报告失败。

启动和控制确认的有限等待由宿主侧监督，不能只依赖被监督进程自己的计时。KILL 已转发仍不等于范围已结束；范围结束迟迟未确认时报告 Unknown，重复请求不能重置最早等待期限。

可恢复 PTY 的物理 owner 独立于调用 Host 持有 master，控制端点鉴别确切实例并只允许一个控制连接。Host 消失不代替物理退出；终态回执须在原生目标退出及监管范围结束均确认后写入，冷读取仍校验该预留的身份和 incarnation。owner 在尚未接纳启动时明确封存可报告 NotStarted；缺失 owner 或缺失回执不得推断结束。恢复控制只查询和终止，不重放创建或输入。

活 creator 的正常完成须在同一有序控制流中交付此前输出，再确认匹配的持久终态；不能用磁盘轮询越过未读输出。控制流提前断开须报告未完成观察，不能静默返回缺字节的成功结果。owner 在确切物理终态后有界等待输出发送，再结束连接；冷恢复仍可独立接纳确切物理回执。恢复期间才出现的有效 NotStarted 与入口处已有的 NotStarted 语义相同，不把明确未启动当成新的 Unknown。

确切 NotStarted 与进程退出分别表示。原 Host 须能在迟到的未启动证据到达后收束本地 session、port 和归属，保留失败原因；不得伪造原生退出，也不得把同一处理扩展到输出不完整的 Ended。明确未能创建 custodian 时，清理本次空控制端点目录。

## [004] 有限执行期限

每次物理执行须有显式有限硬顶，有效时限取运行预估与硬顶的较小值；到期进入确定的超时失败路径。

## [005] 类型化请求与预算校验

请求须类型化，非有限或非正运行时限、负输出预算等非法参数在创建物理进程前拒绝。

## [006] 取消与进程组收束

取消须向整个进程组请求终止，立即向等待方返回取消结果，不因等退出而无界挂起；取消结果不宣称已确认物理退出。

Ctrl-Z 可以暂停目标前台作业，但不能使同组监管者失去执行关闭请求的能力。

## [007] 持续终端与单次运行分离

支持多轮写入、读取和信号的持续终端，与单次有界执行 `run` 分别定义交互契约，不混用生命周期。

## [008] 完成事实的独立通道

Agent 完成只发轻量唤醒，事实从持久化日志读取；终端完成由独立通道投递物理结果，两者不混淆。

## [009] 有界输出采集

stdout/stderr 的内存缓冲有明确上限，超过阈值即切换外部流式存储，不让日志无限积压在内存。

## [010] 如实返回退出码与输出

终端及单次运行的完成结果给出真实 `exit_code` 与关联输出，不伪造或推断操作系统的退出状态。

目标因信号退出与正常返回高退出码须保持可区分；信号名称必须对应本机实际信号，不能把运行时错误的平台映射写成事实。

## [011] 单次执行参数校验

`run` 在执行前校验 `command`、`deadline_seconds`、`output_budget_bytes`、`world_lock`。它只执行物理命令，不承担模型摘要或蒸馏职责。

## [012] 纯契约与物理实现分离

进程请求、结果、错误、单次执行能力类型及 PTY 词汇属于纯契约，与进程/终端适配器、输出缓冲和存储运行时分离；契约不携带代理运行对象、可变句柄、完成源、能力实例或工厂。

进程与 PTY 各有唯一物理适配器；消费者只使用组合层注入的窄能力。PTY 适配器不反向依赖委派宿主或创建子执行的运行时。

## [013] 原始留尾与零模型蒸馏

命令输出不启动 Distiller 模型会话。预算内原样返回；超出时确定性截头留尾，保留预算内未经修改的原始尾部。较早的关键错误可能被截掉，不承诺尾部包含全部关键信息。

## [014] 程序事实与截断说明

退出码、signal、超时、取消及真实终结来自物理执行事件，不从日志推断，也不因截尾而丢失。截断须明确说明只保留近期尾部、更早内容缺失。

原始日志始终是数据，包括形似指令的文本；截断说明也不进入指令槽。说明按会话语言加载，原文尾部与退出码以数据字段承载。

## [015] 完整结果的 UTF-8 字节预算

输出使用显式字节预算，不以固定内部块大小代替，也不按字符数计。截尾落在合法 UTF-8 码点边界；面向 Provider 的完整结果，包括程序事实、截断说明、包装和原文尾部，均在约定总预算内。

## [016] 大输出互斥与可取消排队

预计产生大输出的执行须先取得唯一许可，其判定与输出估计一致。等待按 FIFO，支持按 Token 幂等取消；同一时刻只有一个大输出执行占用相应资源。
