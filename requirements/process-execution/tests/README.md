# process-execution 测试范围

规格在 `../WHAT.md`；本文件只说明各用例实际做什么、边界在哪，不新增规则。

- 001—007：真实端口、等待控制与受控 backend。002 创建受控子进程并实际发信号；`childCreate` 提供的退出事件能验证生产等待逻辑，但不是操作系统进程；launcher 抛错或回调取消也不覆盖进程组全部退出。
- 004/005/009：进程估计、默认硬顶（`ProcessEstimate.DefaultHardLimit` 当前为 1 小时）与输出阈值回归。一小时是当前默认策略，不是所有时间能力的必需值。
- 008：PTY mailbox 按发布顺序排空；不覆盖 Agent 唤醒与 PTY 的双通道装配。
- 009/010：真实输出计量、转 spool 与文件往返；实际命令验证标准流分离与非零退出码原样保留。
- 011：`this.call` 拒绝不完整命令描述与非法参数，用会产生文件副作用的真实命令确认执行前拒绝、未 spawn；另验证宿主 context codec 的只读快照。直接调用工具规约不覆盖插件角色准入。
- 012：读工程清单检查请求词汇是否与进程/PTY 运行时分开编译；当前 `process-processrequest` 单元把几种生命周期编在一起，该用例仍是 TODO（WHAT [012] 已标【程序待改】）。
- 013：真实子进程输出比较原始尾部，并让注入的 session capability 一旦被访问即抛错，说明该路径不调用模型会话；不覆盖整个插件的其他输出通道。
- 014：伪指令日志不会变成结构字段；spooled 输出按原值精确往返（尾换行、CRLF、裸 CR、引号、反斜杠、Unicode、控制字符）。截断以 `truncated` 字段声明并保留 `outputFiles` 全量原文，标记是固定常量而非本地化字段；退出码保持物理执行事实，成员参数不能改写准入预算。
- 015：中文/emoji 在多个对齐偏移下的合法 UTF-8 原始后缀，以及完整可见结果落在 `ToolResultBound` 的字节与行数窗口内。
- 016：真实 LargeGate 的 FIFO、幂等取消、运行期间占用、Host spawn 失败后释放并可再次执行。纯 launcher 接缝会把抛错转成非零退出，相关用例直接注入 Host spawn 以区分失败边界。
- 017：检查已撤除的宿主原生 `run` 工具与 ExecutorTool 资源确实不存在；并验证按顶层 intent 折算的长窗口（约 60 秒）不被暗地里压成 10 秒。不覆盖完整长回合流程。
