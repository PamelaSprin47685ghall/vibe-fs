# provider-projection 测试说明

行为规范见 [WHAT.md](../WHAT.md)。本目录验证 LLM 面向的上下文投影、提示词渲染及数据隔离行为。

## 测试覆盖重点

- **001/002/004/006**：直接调用生产投影模块，验证快照隔离、输入不可变性、Host 元数据对齐、规范化排序、同值幂等及冲突检测。
- **003/005**：验证 Host 编解码器的有效编解码与语义层/线路层隔离。
- **007/013**：验证投影边界（功能命名空间越界被拒绝）与合成表示的转义、空值、必填字段及指令/数据分离。
- **009**：覆盖接收语义（指令面与数据面）及确定性渲染。
- **010**：验证配对编程模式下的提示词注入不伪造消息、原输入保持不变。
- **014**：验证 Join 结果与热启动附录的组合渲染，确保责任说明始终置于全部数据之前。

## 运行方式

先执行标准构建，再使用验证系统运行器执行：
```sh
TESTS_MJS_FILES="$(rg --files requirements/provider-projection/tests | rg '/[0-9]{3}\.test\.mjs$' | sort | paste -sd, -)" node requirements/verification-system/tests/run.mjs
```
