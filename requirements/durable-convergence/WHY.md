# durable-convergence — WHY

多个副本可以各自合法地产生事实。按时间或版本挑赢家会静默丢失已发生的分支；同样的历史得到不同业务状态，又会让同步后的双方继续生活在不同现实里。保留事实、确定地折叠，并把真正的业务冲突交给显式裁决，才能让收敛可解释。

历史保留窗口限制长期成本，但下载旧快照不能让旧 writer 重新变年轻。将 producer activity 与内容身份一起传播，才能让不同副本在同一截止时刻淘汰同一集合。窗口内完整保留与窗口外整体退出，是两个不同边界。

由用户 Git 操作触发、以普通 Git 远端存储，避免增加另一套后台发布系统。安装同步能力不能破坏用户原有的分支获取；只添加缺失的 store 与 heads 映射，才能既修复不完整配置，又保留用户选择。

没有变化时复用已知快照，有变化时只处理必要数据，可以减少同步对在线追加的阻塞；缓存只是节约工作，不能替代事实或绕过竞争核对。
