## 未交付子工作的作废合同

未交付的子工作**永不写完成**。交付不可能时（被取消或重启加载期清理上一进程遗留的孤儿子工作），系统追加 `ChildWorkVoided` 事实结清父方义务；底层 handle 仍可复用，join 报告一次 `voided` 后该工作单元格退役（`Retired`）。

## 运行方式

先执行标准构建，再使用验证系统运行器执行：
```sh
TESTS_MJS_FILES="$(rg --files requirements/delegation/tests | rg '/[0-9]{3}\.test\.mjs$' | sort | paste -sd, -)" node requirements/verification-system/tests/run.mjs
```
