# work — WHY

同一件事不能有两套生命周期。Plan work 与 Manager work 共用一套事件、一套结束工具和一套结果名，差别只由开立时写下的 sequence 导出：S1、S2、S3 是一段式交互，S4 是两段式自动。

评审回答的是这一任离目标还有没有缺口。Promoted 与 Stayed 是这次评审的结果，不是退休结果。Relayed 与 Delivered 才决定是换任还是收束。证书和快照都不能替这两次判定说话。

后继要接手的是底稿与前任声明的视图，不是前任的整段物理对话，也不是机器二次物化的合成记录。剥除前任 assistant 与 tool，由前任经 ANCHOR `view` 声明交棒（durable checkpoint 与 `extra`），才能让每一任看见自己的边界，而不把旧字节再翻译成新事实。

有任期而评审尚未落盘时，人还可以读和观察，但不能写源码，也不能向固定 DevOps 派工。这道门窄在写入与派工，不是把一切工具关掉。
