# time-capability 测试说明

规范见 [WHAT.md](../WHAT.md)。测试验证时间能力的显式注入、Deadline 纯计算、虚拟时钟与定时器实现及模块分居。

## 测试覆盖重点

- **001**：虚拟时钟实例间相互独立，时间推进互不影响。
- **002**：基于起始时刻与预算的 Deadline 计算、精确边界判定、时区等价性及大预算分段等待。
- **003**：虚拟定时器的推进、到期触发、取消与资源清理。
- **004**：源码扫描确保 Domain/Application/Session 模块不直接读取物理时钟或调用全局定时器。
- **005**：注入时钟驱动 Deadline 判定，同一时间值结合不同时钟状态得出各自结果。
- **006**：等待超时的截止退出路径，超时返回 WaitTimedOut 并释放登记。
- **007**：会话起点投影保持首次绑定时刻，支持中英文经过时间（elapsed）渲染。
- **008**：契约、适配器、虚拟实现与表示层的模块解耦与单向依赖结构。
