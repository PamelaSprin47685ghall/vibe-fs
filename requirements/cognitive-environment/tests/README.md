# cognitive-environment 测试说明

规范见 [WHAT.md](../WHAT.md)。测试验证材料分层、组合顺序、提示词隔离及动态提醒行为。

## 测试覆盖重点

- **003**：检查提示词装配顺序（Common Law → Role Law → 继承书籍，含 Bookkeeper）。
- **005**：检查生成的双语角色提示词不暴露 `fast-*` / `deep-*` 等内部机器路由名称。
- **012**：检查 Manager 系统提示包含完整的 Role Law 与 Quality Ledger。
- **013**：检查 Pair Hint 携带绑定语言锚点、resetScope 状态闭环口诀，不携带条件初始化命令或多余推理格式，完整纪律归入 Common Law。
- **016**：检查 Pair Hint 不承载微原语（如 assume、publish、todowrite 等）行为说明。
- **017**：检查宿主提示不携带依赖状态的伪命令，角色和阶段资源不让模型猜测宿主状态门槛。
- **018**：检查 Provider 请求的 Scope steer 按实见语言渲染，不改写历史消息与工具结果，首次委派协商在受理时解锁。
- **019**：检查工作生命周期推进仅通过 review，不向模型暗示二级确认；材料交付使用独立的 wxs_deliver。
- **001/002/004/006/007/008/009/010/011**：材料所有权与各层隔离的断言待接入完整请求通道。
